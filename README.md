# 🎁 しんせつガチャ

**ガチャをまわすと「ちいさな親切ミッション」が出てくる。やってみて、スタンプを集めて、やさしさのバトンをつなぐ。**

「人を喜ばせる」を、**手紙という“言葉”ではなく、日常の“小さな行動”**で実現するWebアプリです。
エレベーターのボタンを押す、家族にお茶を入れる、同僚の仕事を具体的にほめる——
ガチャの“ワクワク”を借りて、ふだんなら素通りしてしまう親切のきっかけを毎日ひとつ届けます。

## コンセプトの根拠（研究より）
- **親切は、した本人も幸せにする**：親切行動の介入研究27件のメタ分析で、行った側の幸福感が小〜中程度上がる（δ=0.28）。
  Curry et al. (2018) https://doi.org/10.1016/j.jesp.2018.02.014
- **「1日に5つ」がポイント**：Lyubomirsky らの実験では、週の特定の1日に5つの親切をまとめて行ったグループで幸福感が上がった。→ アプリの「しんせつデー（1日5つ）」ゲージ。
  https://ncbi.nlm.nih.gov/pmc/articles/PMC4380267/
- **良いことに目を向ける・味わう**：「3つのいいこと」やセイバリング（味わう）は幸福感を高める習慣として知られる。→ 「じぶん」ジャンルのミッションと、達成後の気持ち記録。
  https://ggia.berkeley.edu/practice/three-good-things

## 使い方
1. **ジャンルをえらぶ**（まちの人／いえ・家族／しごと・学校／ともだち／じぶん）
2. **ガチャをまわす** → ハンドルが回ってカプセルが出てきて、ミッションが登場（ノーマル／レア／スーパーレア）
3. **「やってみる！」** → 今日のどこかで実行。むずかしければ「ほかのにする」（1日3回まで）
4. **「できた！」** → スタンプ＋紙吹雪。気持ち（😊😌😆😳💪）とひとことメモを記録
5. **やさしさのバトン** → シェア用の画像カードと、受け取った人が同じミッションに挑戦できるリンクを共有（LINE/SNSなど）

## 機能一覧
| 画面 | 内容 |
|---|---|
| ガチャ | カプセルトイ風マシン、レア度演出（SRは虹色＋紙吹雪）、ジャンル絞り込み、引き直し1日3回 |
| きょうのやさしさ | 1日5つの「しんせつデー」ゲージ（研究に基づく目標） |
| 達成 | スタンプ演出、やさしさポイント（N=1/R=3/SR=5）、気持ちとメモの記録 |
| バトン | 1080×1080のシェア画像をその場で生成、Web Share API（非対応ならリンクをコピー）、`?baton=ID&from=名前` で受け取り画面 |
| ずかん | 全48ミッションのコレクション。達成数・連続日数・コンプリート率 |
| きろく | 5週間のやさしさカレンダー（ヒートマップ）、気持ち・メモつき履歴、ニックネーム設定、記録の全消去 |

## 「てれてがみ」との違い
| | てれてがみ（joy） | しんせつガチャ（joy2） |
|---|---|---|
| 喜ばせ方 | 言葉（手紙）で想いを伝える | 行動（ちいさな親切）でさりげなく |
| 相手 | 特定の1人 | まちの知らない人・家族・同僚・友だち・自分 |
| 頻度 | 記念日・節目に1通 | 毎日ちょっとずつ、習慣になる |
| 誰が喜ぶ | 受け取った人 | 親切された人 ＋ 親切した自分（研究で実証） |
| 広がり方 | 1対1で届く | バトンで「次はあなたの番」と連鎖する |
| 体験 | 質問に答えて書く | ガチャ・スタンプ・ずかんで遊ぶ |

## 技術・プライバシー
- 純粋な静的サイト（HTML / CSS / JavaScript）。ビルド不要、外部ライブラリ・外部フォント・解析ツールなし
- データは端末の `localStorage` のみ。サーバーへの送信は一切なし
- スマホ優先レイアウト、セーフエリア対応、`prefers-reduced-motion` で演出オフ
- ミッションは `missions.js` を編集するだけで追加・変更できます

## ローカルで動かす
```bash
cd shinsetsu-gacha
python3 -m http.server 8080
# → http://localhost:8080/ をスマホサイズで開く
```
GitHub Pages / Netlify / Cloudflare Pages などにフォルダごと置けば公開できます（バトンリンクは公開URLで機能します）。
